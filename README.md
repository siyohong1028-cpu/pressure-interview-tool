# 压力面试题库生成中心

> 智能生成压力面试问题，支持 PDF/DOCX/PPTX/TXT 上传，AI 语义分析，自填问答

## 🔗 在线使用

👉 **[打开网页](https://siyohong1028-cpu.github.io/pressure-interview-tool/)**

## 功能

- 📄 上传 PDF / DOCX / PPTX / TXT 简历或文档，自动提取内容
- 🤖 AI 生成 8 个压力面试问题（由浅入深，尖锐犀利）
- 📝 自填问答区（默认 2 个，可添加更多）
- 📊 四维度 AI 分析（逻辑性 / 思考深度 / 具体程度 / 应变能力）
- 💡 个性化提升建议（针对受访者回答的改善指导）
- ⚙️ 支持 DeepSeek / 豆包 API
- 💾 自动保存 + 历史存档（localStorage）

## 使用方式

1. 点击右上角 ⚙️设置，填入 API Key
2. 上传 PDF/DOCX/PPTX/TXT 文件
3. AI 自动生成题库
4. 在每个问题下记录受访者回答
5. 点击"AI 分析"和"提升建议"获取反馈

## 技术栈

- 纯前端：HTML + CSS + Vanilla JavaScript
- PDF 解析：pdf.js
- DOCX 解析：mammoth.js
- PPTX 解析：JSZip
- AI 接口：DeepSeek / 豆包 API
